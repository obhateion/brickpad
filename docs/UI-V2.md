# BrickPad UI v2 — техническое задание

## 0. Цель
Функционал 1.2 не меняется, меняется подача: новичок понимает интерфейс без мануала. Один экран — один вопрос, на экране не больше 4–6 параметров, остальное глубже.
Не ломать: формат проекта (.bpp), аудиодвижок, производительность звука, freeze, экспорт. Аудиопоток никогда не ждёт интерфейс.

## 1. Два вида интерфейса
PROJECT › SYSTEM › ИНТЕРФЕЙС › ВИД:
- ПРОДВИНУТЫЙ (по умолчанию) — все функции, навигация «лестницей».
- ПРОСТОЙ (опция) — режимы ИГРА / НОТЫ / ЗВУК, крупно, для игры и для детей.
Переключение мгновенное, песня играет дальше. Оба вида работают поверх одних данных и действий.

## 2. Продвинутый вид: лестница
ГЛАВНАЯ: ПЭДЫ · СЦЕНЫ · МИКШЕР · ПРОЕКТ
└─ ПЭД (любой из 12)
   ├─ ПАТТЕРН: шаги · ролл · выбор паттерна и FOLLOW · запись
   ├─ ЗВУК: страницы движка по 4–6 параметров · пресеты · файл · ЕЩЁ…
   ├─ ЭФФЕКТЫ: инсерт 1 · инсерт 2 · посылы A/B
   ├─ МОДУЛЯЦИЯ: LFO 1–4 · автоматизация · DUCK
   └─ МИКС: громкость · пан · посылы · FREEZE
Пока не вошёл в категорию — её содержимого не видно. Редкие параметры — последней страницей «ЕЩЁ…».

Кнопки (закреплены, НЕ настраиваются):
- EDIT — войти глубже; удержание + стрелки — значение (←/→ точно, ↑/↓ грубо)
- Y — назад на уровень выше, всегда
- F1/F2 — соседний элемент того же уровня: на главной категория, внутри пэда соседний пэд (остаёмся на той же странице)
- L1/R1 — соседняя страница внутри категории
- SHIFT+стрелка — прыжок внутри пэда: ↑ ПАТТЕРН, → ЗВУК, ↓ ЭФФЕКТЫ, ← МИКС
- SHIFT (удержание) — шпаргалка всех сочетаний этого экрана поверх него
- PLAY — как сейчас; F1+F2 — PROJECT; MENU 3 с — выход
Существующие сочетания (undo, сброс, копировать/вставить и т. д.) сохраняются, но показываются только в шпаргалке.

Всегда включено: память позиции на каждом уровне; хлебные крошки сверху («NEON › 04 BASS › ЗВУК › ФИЛЬТР», справа «2/5»); подвал максимум 3 подсказки; пустые состояния подсказывают действие; поп-ап значения при удержании EDIT.

Настройки (PROJECT › SYSTEM › ИНТЕРФЕЙС): полоса пэдов СКРЫТА / ТОНКАЯ / КРУПНАЯ (12 пэдов под крошками: цвет движка, прогресс клипа, выбранный); подсказки в подвале ВКЛ / ВЫКЛ. Других настроек навигации не делать.
Каждую страницу верстать под крупную полосу — при тонкой/скрытой она просто свободнее. Одна версия экрана.

## 3. Простой вид
ИГРА (плитки пэдов, запуск, EDIT+↕ громкость, Y заглушить, сцены), НОТЫ (только шаги и ноты пэда), ЗВУК (4 параметра на стрелках с понятными именами: ЯРКОСТЬ=cutoff, ВИЗГ=резонанс…; SHIFT+X случайный звук). Режим: MENU + ↑/→/↓. F1/F2 — пэд.
Детский замок (опция): нельзя удалять и перезаписывать, только «сохранить как новый»; выход из простого вида — удержание F1+F2 ~3 с с индикатором. Делать последним.

## 4. Темы
Стиль макетов = тема «Космик» (по умолчанию). Позже: Матрикс (зелёный монохром), Кровавый бетон (серый + тёмно-красный), Янтарь (оранжевый монохром), Геймбой (светлая оливковая).
Правила: в коде интерфейса ни одного зашитого цвета — только токены (bg, panel, line, text, dim, accent, eng_sampler, eng_grand, eng_acid, eng_cloud, cat_pattern, cat_sound, cat_fx, cat_mod, cat_mix, warn); тема — файл в themes/ (совместить с текущим форматом). Движки и категории различаются ещё и метками (SMP, GRD, ACD, CLD), иначе монохромные темы не работают.
Космик: bg #0B0C10, panel #161820, line #2A2E3A, text #E8E8E8, dim #626877, SAMPLER #3FE0D0, GRAND/эффекты #FF4FA3, ACID #FFD23F, CLOUD/модуляция #5AA0FF, паттерн/play #7CFF6B, микс #FF8A3D, запись/mute #FF5A5A.

## 5. Архитектура
Три слоя: данные (есть) → действия (launch_clip, set_param, select_pad, toggle_mute, copy/paste, undo…; кнопки вызывают действия, а не меняют данные напрямую) → вид (экран = отрисовка + таблица «кнопка → действие»). Продвинутый и простой виды — две раскладки поверх одних действий.
Навигация — стек экранов (push/pop), у экрана: заголовок, страницы, on_input, draw, сохранённая позиция.
Параметры движков описать данными (id, имя, короткое имя, диапазон, страница, «ЕЩЁ…»), страницы строятся автоматически.
Перерисовка только при изменениях или ≤30 fps; волны и тяжёлые графики кешировать.

После каждого шага: сборка, запуск на Brick, DEMO/NEON открывается и звучит как раньше, коммит.
