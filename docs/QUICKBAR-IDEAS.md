# Quick bar: what else could live there (2026-11-20)

Now on the bar: METRONOME (sound), HEAR NOTES, CAPTURE, TEMPO DOWN / TEMPO UP (nudge while held), PADS, KEYS.
Metronome vibration is in PROJECT > METRONOME only.

The rule for the bar: one press, an instant result you need *while playing*. Anything you set once and forget stays in PROJECT.

## Transport and timing
1. **TAP TEMPO** — tap EDIT in rhythm, the tempo follows after 4 taps.
2. **COUNT-IN** on/off — the 1-bar count before recording.
3. **LAUNCH QUANT** — cycle NONE / 1/4 / 1 BAR / 2 / 4 bars (now in PROJECT > PLAY-REC).
4. **LOOP SCENE** — lock the current scene, follow actions are not applied.
5. **FOLLOW** on/off — globally pause every follow action.

## Recording
6. **REC ARM** — the same as MENU+PLAY, but visible as a lamp.
7. **OVERDUB / REPLACE** — record over the notes or replace them.
8. **REC QUANT** — snap recorded notes (OFF / 1/16 / 1/8).
9. **RESAMPLE** — record the master output into a new pad sample.

## Sound and mix
10. **MASTER FX BYPASS** — hear the dry mix for a moment (held = temporary).
11. **FILTER SWEEP** (performance) — hold, the d-pad moves a master LP/HP filter, release returns.
12. **MUTE ALL / UNMUTE ALL** — or "back to the saved mutes".
13. **SOLO CLEAR** — remove every solo at once.
14. **CPU / LOAD** — the audio load lamp, red over 70 %, press shows the load per pad.
15. **MASTER VU** — a tiny level meter built into the button.

## Editing
16. **UNDO / REDO** — two buttons, the most frequent action.
17. **FOLLOW PLAYHEAD** — the step page scrolls with the playing step or stays.
18. **SNAP** — note grid in the piano roll (now in PROJECT > TEMPO).
19. **COPY / PASTE** of the current pattern or pad.
20. **RANDOMIZE** — the pad's random generator (now SHIFT+X / OPTION menu).

## Navigation and device
21. **SCENE ‹ / ›** — switch scenes without the GRID.
22. **SAVE** — quick save with a lamp "not saved".
23. **KID LOCK** — locks everything except play.
24. **BATTERY / CLOCK** — a quiet indicator (no press).
25. **MIDI** lamp — lights on incoming MIDI/clock, press = MIDI LEARN.

## Suggested next set
Most useful, in order: UNDO, TAP TEMPO, REC ARM, COUNT-IN, LAUNCH QUANT, SAVE (lamp), CPU lamp.
Better as a choice in PROJECT > SETTINGS > QUICK BAR: the user picks 6–8 of these buttons.
